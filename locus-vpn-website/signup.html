What happens next

  1. We email you a confirmation link and your subscription code. The account is inactive until you click the link.
  2. You install the client for Windows, macOS, Linux, iOS or Android and enter the code.
  3. The first activation binds the code to that device's hardware fingerprint, which is how the device limit is enforced.
  4. You can move up or down a tier whenever you like; changes are charged pro-rata.

Replacing a device

If you no longer have the machine a code is bound to, support can unbind it so it activates elsewhere. Every unbind is logged with a reason. See how activation works.

Billing and refunds

Payment is handled by the checkout step and the 30-day refund applies from that date. See the refund policy for the details.

Cancelling

Cancellation is two clicks in the dashboard, with no retention call. See refunds for pro-rata rules on annual plans.
